# List View Preferences

The list view preserves the configurable warehouse fields shown in the supplied screenshots and adds RFID operational fields.

## Existing warehouse fields
- ASN/Receipt
- Owner
- Description
- Pack
- UOM
- PO / SO
- Status
- Lottable01–Lottable10
- Manufacture Date
- Expiration Date
- Delivery By Date
- Best By Date
- Temperature
- Received Date
- QC Required
- QC Status
- UDF1–UDF5
- Lot Number

## RFID fields to expose as optional columns
- EPC
- SKU
- LPN
- Location
- Expected Qty
- RFID Qty
- Variance
- RFID Status
- Last Seen
- Last Seen Location
- RSSI
- Tag Seen Count
- Reader
- Scan Session

The dashboard can use these fields without forcing every user to display every column.
